# Wiki-Schicht

Hier liegt ausschließlich die freigegebene, aus Quellen abgeleitete Wissensschicht. Modelle erzeugen nur Patches; direkte Schreibvorgänge auf `main` sind nicht zulässig.

Jede Wiki-Seite folgt dem Frontmatter- und Zitationsschema aus [`../llm-wiki.md`](../llm-wiki.md). Technische Verträge und Abnahmekriterien stehen in [`../spec.md`](../spec.md).
